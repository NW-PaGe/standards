Writing pages

This page shows each element that the template styles. Copy the element that you need and change its text.

Callouts

NoteA note

Use a note for extra information.

TipA tip

Use a tip for advice that saves time.

WarningA warning

Use a warning for an action that can cause a problem.

NoteA collapsed callout

The reader opens this callout to read more.

A minimal callout has no title bar.

Code

A code block can show a file name.

hello.py
def greet(name):
    return f"Hello, {name}"

A code block can number its lines.

python
first = 1
second = 2
total = first + second

A terminal block shows a command and its output. A line that starts with $ and a space is a command.

Terminal
echo "Hello"
Hello
